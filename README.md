# Otthon Varázs – weboldal

Az oldal egyetlen fájl: **index.html**. A képek az **assets** mappában vannak.
Szerkesztés a GitHubon: kattints az `index.html`-re → ceruza ikon → módosítás → **Commit changes**. Pár perc múlva frissül az élő oldal.
Kereséshez a szerkesztőben: **Ctrl+F** (Macen Cmd+F).

## Ár módosítása – példa
`['Tisztasági festés',1500,3500,'1 500–3 500 Ft/m²']`
Az **1500** és **3500** a számoláshoz kell (szóköz és Ft nélkül), az utolsó rész a kiírt szöveg. Mindkettőt írd át.

## Kép cseréje
1. Töltsd fel az új képet az **assets** mappába (Add file → Upload files) **ugyanazzal a névvel**, mint a régi – így felülírja.
2. Fotó: JPG, legfeljebb kb. 500 KB, 1600 px széles.

## Fontos
- Csak a szöveget írd át, a `< >` jelek közti részeket és az idézőjeleket hagyd meg.
- Ha valami elromlik: a fájl **History** gombjával bármelyik korábbi változat visszaállítható.
- A **.nojekyll** fájlt ne töröld.
